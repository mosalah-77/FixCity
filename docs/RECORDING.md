# Record an Android walkthrough

Aim for a continuous two-minute recording with a short pause after each result. Use the signed release build and fictional details. The emulator's built-in recorder captures its Android display, without the Mac desktop or mouse pointer.

## Start and save

1. Open FixCity in the Android emulator. Choose your language and start a demo workspace before recording. Keep the phone upright and avoid resizing the emulator during the take.
2. Open the emulator's **More (…) → Record and Playback** controls. On macOS, **Command + Shift + R** opens these controls too.
3. Click **Start recording**, then return to the app. Leave the entry screen visible for about two seconds.
4. Follow the sequence below. Let each page finish loading before moving on; scroll steadily and keep confirmation messages visible long enough to read.
5. Return to **Record and Playback**, click **Stop recording**, choose **WebM**, then **Save**. Keep the original recording. WebM preserves motion better than an animated GIF.

If Android's **Show taps** or **Pointer location** developer option is enabled, turn it off for the take. Avoid recording with a Mac desktop recorder, which can include the pointer and surrounding windows.

## Suggested sequence

| Screen | Action and suggested text |
| --- | --- |
| Demo menu | Pause on the synthetic-data notice, then choose **Citizen**. |
| Home | Briefly show **Report**, **Track**, categories and recent reports. Choose **Roads**. |
| Report form | Enter: “A pothole beside the sample school entrance needs repair.” Choose **Demo North**, use the **Damaged road** sample photo and keep the demo location. |
| Confirmation | Review the details and submit. Pause on the saved tracking code. |
| Staff review | Open **Demo menu → Staff review** and your new report. Add: “Reviewed the sample report and confirmed its district.” Attach an optional **Damaged road** photo, then choose **Send to district**. |
| District team | Open **Demo menu → District team** and the same report. Add: “The district crew has started work.” Choose **Start repair**. You can now save progress notes without closing the report. For completion, select **Resolve report**, enter “Repair completed and checked in this demonstration.”, attach **Repaired road**, and choose **Mark resolved**. |
| Citizen tracking | Return to **Citizen → Reports**. Open the report and select **Track this report**. Pause on **Resolved** and the history entries and their photos. End here. |

Use natural navigation throughout. Keep small pauses and genuine loading states; avoid jumps between still images. If something fails, stop, check the problem and make a new take. Do not edit a failed save into an apparent success.

The recording shows a synthetic prototype. It does not establish government use, physical repair work or live availability. Preserve the original team credits when publishing it.

Recorder controls: [Android Emulator documentation](https://developer.android.com/studio/run/emulator-record-screen).
